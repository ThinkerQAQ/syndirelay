# SyndiRelay 文档

[English](../index.md) · [项目首页](../../README_ZH.md) · [Inkerio 引擎](https://github.com/ThinkerQAQ/inkerio)

**SyndiRelay 是由 BlogCTL 拆分出来的独立 Markdown 编译与内容分发工具。** 静态网站由 Inkerio 生成；SyndiRelay 可选地负责编译和站外分发。单文件编译不需要安装博客引擎或个人内容仓库。
