# 可选的 Reverfolio 影响力统计

SyndiRelay 负责分发，Reverfolio 负责统计，两个应用保留各自的数据与部署方式。在「设置 → 影响力统计」中启用交接，填写本地 Reverfolio 地址、已有 API token 文件的绝对路径、稳定来源标识，明确选择主原文语言及新作品的监测开关。只填写凭据文件路径，不把密钥粘贴到聊天中。

原文域名和中英文文章路径使用现有站点配置；文章 slug 是稳定标识。公开发布或更新成功后，程序只把标题、原文 URL、语言及公开发布 URL 写进本地队列。正文、草稿、Cookie 和密钥不会交接。统计服务离线不改变发布结果，也不需要重新发布文章；队列在重启后恢复，自动退避重试，也可在设置页查看问题、手动重试。

已有作品的监测选择不会被覆盖。文章归属或原文 URL 冲突会保留为待处理错误，不会悄悄改绑。关闭交接会暂停队列而不删除数据。历史发布记录需要主动导出、预览并选择导入，不会自动把所有历史文章纳入统计。

完整字段、接口和时间口径见[英文配置说明](../how-to/reverfolio.md)及 Reverfolio 的统计图说明。
