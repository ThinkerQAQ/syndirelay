# SyndiRelay

A standalone, cross-platform Markdown publishing and syndication tool, extracted from BlogCTL.

**Status:** Private migration workspace. The compiler, browser Bridge/Extension and platform adapters are being migrated byte-for-byte first; no new platform capability or legal authorization is implied by this repo. Public release is blocked pending compatibility, privacy and API-authorization review.

See the migration branch for the original source snapshot and compatibility tests. Do not commit private articles, cookies, access tokens or local publication databases.
